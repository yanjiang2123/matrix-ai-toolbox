Safe by design

公开的是能力，不是公司的数据。

公开仓库移除了公司环境、真实连接、数据库驱动、测试数据和运行产物。使用者需要接入自己的数据库与模型服务。

✓

连接信息

仅发送到本机服务并保存在当前进程内存，不写回项目配置。

✓

AI 密钥

由使用者在运行时填写；网站和公开源码不包含公司账号或密钥。

✓

执行边界

AI 只提供分析和验证 SQL，不自动执行建议，最终操作由使用者确认。

Honest scope

项目边界也写清楚。

AI需要使用者提供兼容的接口地址、模型与密钥；未配置时，本地规则分析仍可工作。

数据库需要使用者提供对应 JDBC 驱动和可用 JDK，工具不内置商业驱动。

图片 OCR当前依赖 macOS Vision；其他系统需要继续扩展 OCR 适配器。
